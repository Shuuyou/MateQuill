# 本店今日提案：实现与隔离验收

## 已实现

首页仅在已登录真实门店、无总部任务时预备一个本店方向；访客不会自动调用模型。服务端以当前企业、本人、门店、中国日期和资料版本持久化任务。并发进入、丢失 POST 响应与刷新只恢复同一真实 Agent 任务；日期、六小时时限和资料版本控制有效期。采用进入原会话，跨店采用被拒绝。

自主任务读取当前产品资料与门店记忆，先定位，再沿查到的街道、园区或实体交叉研究周边，比较候选人群，准备自然朋友圈与三分钟内的体验计划。没有预置高校、学生比例、销售量、活动或价格答案。

本轮预备交付为文案及可选已有真实图片。已有的同型号官方素材仍按来源、哈希与图片审阅结果选用；没有合适图片时准确交付纯文案与拍摄计划。拍摄计划不算成图，也不触发新图片生成。此权限由服务器上下文控制，普通生成及其他平台的图片标准保持原有规则，用户提交同名字段不能绕过。
