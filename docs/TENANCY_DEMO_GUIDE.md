# 企业与门店协作演示

本地入口：`http://127.0.0.1:3003/`。阿里云新版入口由本轮发布记录提供。魔搭创空间保留既有演示版本。

演示账号由初始化工具生成。开发机读取 `runtime/demo-access.json`，阿里云读取本地保存的 `runtime/remote-demo-access.json`；文件均受 Git 忽略。按文件中的角色登录，不在录屏中展示密码或邀请链接。

## 建议演示顺序

1. **总部发布活动**：企业管理员打开“团队活动”，选择本轮推广产品、参与门店与创作要求，保存并发布。展示各店任务以及不同人群、叙事和场景的分配。
2. **校园店领取创作**：换校园店员登录，领取任务。拍照、录音或输入一句需求，确认必要的产品选择后开始创作。生成过程中刷新页面，继续查看同一任务。
3. **展示成稿与生态**：查看正文、配图、创作思路与来源；打开已有电脑、手机、平板生态成稿，导出 HTML。需要海报时进入设计工作区，调整文字并导出。
4. **店长审阅**：店员送审，切换店长账号，查看正文和选中配图，批注或批准。批准记录关联实际稿件版本。
5. **执行回收**：店员登记发布平台和完成时间，总部查看活动进度。此步骤登记店员完成的发布操作。
6. **独立企业合作**：总部针对合作企业创建活动邀请；合作企业管理员接收后分发给自己的门店。用两个独立浏览器会话展示各自团队与内容。

实机讲解剪辑采用上述流程中的真实应用截图，保留照片输入、新品事实和海报编辑等既有能力的演示画面。录制时优先展示销售员的一句输入和最终作品，再用总部与审核协作说明如何投入实际工作。
