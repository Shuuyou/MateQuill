一句话进入创作，必要时精准澄清

保持输入简洁，让交互只在需要决策的时刻出现。

自然表达就是任务入口

用户可以直接输入：“给设计专业大一新生写一篇 MateBook 14 鸿蒙版的小红书，关心课程软件和手机传资料。”系统结合实际产品目录理解型号与顾客，并组织对应的创作任务。

交互时刻处理方式工作连续性
需求已明确将型号、人群、平台等信息组织成结构化任务，进入生成用一句自然表达启动完整流程
产品存在多个版本从实际目录给出候选，让用户确认具体型号保留原问题，完成确认后继续
顾客信息需要补充集中展示本轮需要确认的问题减少重复填写与逐项打断
需要精细控制用户主动展开补充条件，选择渠道、目标、阶段或创意风格让初次使用与进阶操作共享入口
返回继续编辑恢复当前会话的需求与最近内容任务形成持续工作的创作空间

这一设计把入口的易用性与后台的结构化任务结合起来：对用户保持自然，对生成和验证过程提供明确字段。

05 / 18　产品与技术说明

把产品知识变成结构化证据

事实、条件、原文和来源一同进入创作过程。

面向具体型号组织知识

MateQuill 使用准确产品名称与系统信息组织检索候选，结合门店任务进行相关性排序。资料包既保留产品事实，也保留它来自哪一份文档、哪一段原文、适用哪些条件，使创作过程能够按任务选取依据。

事实与来源字段作用
product / system保持型号和系统归属
label / value把属性与属性值共同表达
quote / source_id将产品主张连接到原文与来源
qualifiers保存配置、机型、版本等适用条件
id / sha256 / captured_at支持引用、内容完整性核对与采集时点追溯

为表达挑选事实，为审校保留原文

写作上下文围绕获准使用的属性值和限定摘录组织；审校上下文保留相关原文证据。这样的上下文分工，让作者集中表达与顾客有关的事实，也让审校阶段能够核对属性归属和条件完整性。

事实预算带来更清楚的阅读主线

平台连接器为当前任务设置事实预算：小红书 3 项、公众号 4 项、朋友圈 1 项、海报 2 项。系统根据顾客任务、卖点主题与限定条件复杂度排序候选，用少而相关的事实支撑一个清晰主张。

“选哪些事实、为什么选、放在哪里”成为可以检查和迭代的编辑决策。

写作与审校分工，形成质量闭环

把事实质量、引用质量和表达质量分别处理。

质量环节检查与处理内容产物
结构化生成按照任务、平台策略和证据生成标题、正文、CTA、事实引用与素材安排具有明确字段的成稿
确定性检查核对引用 ID、产品归属、数字与单位、限定条件、图片来源及结构可定位的问题项
独立语义审校逐句检查产品主张与引用原文的支持关系，同时审阅分镜文字语义判断及具体说明
定向修复结合具体审核意见与编辑要求，执行一轮有目标的修改修订后的文稿
再次核验重新执行规则与语义核验，保留调用轨迹与成稿对应的审核记录

细到属性归属的审核粒度

产品营销中的关键问题常出现在相近属性之间：同一型号的不同配置、接口左右侧差异、软件版本条件、素材文字与正文表述。MateQuill 将这些问题落到事实字段和原文支持关系上处理，使审校能够解释具体主张的依据。

内容条件参与版式，而非停留在后台

正文块与分镜卡片可以携带 disclosures。适用条件与相应产品事实关联，并在正文、卡片或海报脚注层呈现；图片也保留来源和用途元数据。内容形成过程与最终呈现共享同一份依据。

执行过程可观察

生成、审校、修复等模型调用保留耗时、token 用量与结果状态。生成流程设置共享调用预算与有限修复次数，结构化响应遇到可恢复格式异常时支持一次重试，用户需求保持在当前任务中。

审核记录与作品同在：评委可以从成稿一路查看到引用事实、资料来源和运行轨迹。

平台内容组织视觉与互动

版本化创意连接器

四个平台通过同一连接器协议注册：describe、build_brief、normalize_plan、review。连接器封装平台策略、事实预算、创意风格、输出 Schema 和审核规则；新增平台可以复用已有生成与审核流程。

从“写文案”走向“策划一组内容”

CreativePlan 同时保存 narrative_device、reader_tension、reader_gain、title_cover_relation 与 promise_payoff。每页卡片有标题、正文、视觉任务、素材引用和事实引用，标题封面还可生成带理由的测试候选，让内容运营拥有可调整的策略成果。

当前策略库包含 4 个平台、7 个创意策略模板与版本化元数据。课程清单、资料流转和文件交付等手法依据本次需求选择，支持相同产品在不同场景下形成不同表达。

一份任务底稿，可以生成适合不同发布位置的表达结构与视觉节奏。

从设计意图，到渲染后的视觉反馈

结构化艺术方向、程序布局与多模态审稿形成分层视觉管线。

把生成模型接到可控的设计系统

视觉生产从已经核验的文案与产品素材出发。艺术方向模块将布局、密度、图形母题、对齐、主标题尺度和色板归一到设计 token；组合器把这些 token 转成具体图层、坐标与排版。模型的创意提议因此可以被编辑器继续理解和操作。

视觉管线处理内容产出
文案与素材准备选择本次任务的标题、事实卖点、行动引导与产品图统一内容底稿
艺术方向归一构图、留白、字形角色、视觉母题和色板可组合设计 token
程序排版生成图层、文本框、层级和实际几何位置可编辑海报源文档
实际渲染用相同文档渲染 SVG 与指定尺寸 PNG可观察的成品画面
视觉反馈配置视觉审稿模型后，对渲染 PNG 进行多模态审阅结构化检查和布局建议
受控修改校验建议的图层、位置、字号及颜色，支持一次布局修正保留可编辑性的修订文档

视觉审稿围绕实际画面展开

多模态审稿读取真实渲染 PNG，围绕中文显示、产品主体可见性、标题层级、行动引导和背景说明组织结构化反馈。建议通过现有图层 ID 与可编辑属性表达，再进入程序校验，使视觉反馈能够连接到具体编辑动作。

让辅助生图成为设计材料

海报既可以使用品牌色与矢量图形，也可以按用户选择调用图像服务生成辅助背景。产品照片、真实文字和设计几何保持各自图层，便于运营人员继续调整主题表达与版面。

团队与产品愿景

Shuuyou 与 6TDooo 来自杭州电子科技大学具身智能实验室。MateQuill 将对 Agent、证据组织、模型评估与交互系统的理解，凝结成面向消费电子零售的内容工作空间。

我们希望让每一次产品介绍，都能从顾客的任务出发；让每一份营销内容，都有可查的产品依据；让每一次生成，都能继续进入编辑、演示与沟通。
