MateQuill 场景有据

把顾客的一句话，变成有产品依据的多平台内容与销售沟通方案。

团队：Shuuyou、6TDooo · 杭州电子科技大学具身智能实验室

为门店解决什么

导购需要把复杂产品资料转成顾客听得懂的购买理由，同时适配小红书、公众号、朋友圈与门店海报。MateQuill 将需求理解、资料检索、内容创作、事实核验和交付连成一条工作流。

从自然表达开始输入顾客、产品与任务；仅在信息缺失或型号有歧义时澄清。支持查看产品资料、补充条件和恢复当前会话中的近期任务。
内容随场景和平台改变生成标题、正文、行动引导及配图方案，保留引用事实和来源。支持换需求重新生成、复制以及 Markdown／网页导出。

已经实现的能力

产品事实与素材可追溯接入赛事知识库、本地官方资料及可选 ima；按具体型号处理事实、图片与适用条件，生成后执行程序核验及独立模型审校。
顾客沟通延续到销售提供五维客户洞察、3 分钟演示建议和 1／3／7 天跟进草稿；演示条目引用对应产品事实，跟进区分选购与上手阶段。
可编辑的真实文字海报支持理性编辑、字体海报、几何宣言三种构图，编辑文字、位置、字号及间距，导出 PNG、SVG 与源文档。

真实运行样例

任务：为大学生生成 HUAWEI MateBook Pro 的小红书内容。

实际结果：系统生成图文内容并完成审查，返回 4 张配图，复制与导出可用。右侧为真实应用运行截图，展示内容工作区与审查通过状态。

生成失败时保留原需求，支持直接重新生成；格式异常最多自动重试一次，仍执行事实及内容审核。

技术实现

自然输入与型号确认 → 场景／平台策略 → 产品事实与素材检索 → DeepSeek 生成 → 程序核验与独立审校 → 修改与导出

后端使用 Python／FastAPI，前端使用 HTML、CSS 与 JavaScript。自研流程负责业务策略、来源约束、图文组织和审核，知识库提供产品依据。源码包含运行说明、提示词与测试。

当前完成范围

内容生成、资料核验、客户沟通方案与可编辑海报已形成可运行原型。正式报价尚未完成：当前没有接入经授权且有效的四级价格与优惠叠加规则，不展示虚构成交价。客户跟进当前生成计划和草稿，尚未接入外部 CRM 或自动发送。现有运行样例说明功能可用，不代表真实门店转化效果。
