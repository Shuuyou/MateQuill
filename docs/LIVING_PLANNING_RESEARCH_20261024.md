# 让创作保留具体表达：规划层研究与接线

核查日期2026-10-24。本轮由文字、视觉、评测三个实现组先研究后落地，主协调负责规划接线与真实同输入验证。

## 原始依据

- [Verbalized Sampling，v4，2026-07-15](https://arxiv.org/abs/2510.01171v4)：熟悉表达的偏好可能压缩生成模式。多候选本身不等于不同观察；本项目不把模型口述概率当流量概率，也不声称直接复现论文指标。
- [Gacha Decoding，2026-10-01预印本](https://arxiv.org/abs/2610.01382)：以指令跟随和外部随机性探索不同表达模式，提示多样性不只来自temperature。本轮不把固定几种标签的轮换称为Gacha实现，不增加外部随机任务强迫门店玩梗。
- [Anthropic context engineering，2025-09-29](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents)：应调整输入上下文结构，保留高信号材料，避免靠堆提示词修复冲突目标。

## 当前根因与决定

账号声音已允许口语，生成系统却仍普遍要求选择难题、事实回应与互动邀请。视觉自然照片意图也会被下游完整精修渲染覆盖。只加“活人感”形容词、热词或提高温度，不解决这两处冲突。

文字组提供统一`build_editorial_voice`契约，规划与写作读取同一份当前需求、真实素材观察与账号身份；场景提案不冒充已发生经历，结束可以自然停住。主协调将其接入`creative_exploration`，避免规划时先决定通用教程，再在末端强行口语化。原有型号、事实、素材ID校验和调用预算保留。

视觉组调整原生表达和源照片保留的实际路由；评测组建立无新旧标签的成对评阅。实际输出与确定性测试分开：测试验证边界与接线，人类更愿意看哪一份需要读者反馈，不能由自己的模型自评宣布胜出。
