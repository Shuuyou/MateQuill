# 商城资料与品牌图文制作

MateQuill 本轮把素材同步、准确版本检索和视觉制作连成一条链路。产品主视觉、单卖点解释、文字与画面双关、情绪企划和编辑叙事按当前传播任务选择；准确产品、字体、留白与光影可以直接完成一张作品。

## 从参考中学什么

本轮实际读取用户提供的30条小红书原帖。小米研究查看57张图，华为研究查看11张首图，vivo与OPPO研究查看60张图。4篇公众号读取正文，查看27张普通图及63个SVG分区首图；另一篇华为公众号遇验证码，未读取。SVG首图采样不代表已执行所有交互动效。

这些来源包含品牌账号、具体门店、设计师作品集和第三方二创。研究保留作者与发布身份，不将工作室的自述合同认证为品牌官方委托。涉及具体产品能力时使用商城或对应官方规格，参考帖的历史活动和卖点不进入我方事实库。“看海报小字”一帖属于批评讨论，单独分类。

系列内容可以统一字体、光线、色域和品牌轴线，封面、细节、解释图仍各有职责。门店本地化可以在合适位置承接真实体验、地址或活动，不要求每张图重复店名、报价和到店邀请。

## 已进入实际制作流程

- `content_visual_commission`将实际正文、图片职责、发布入口与当次要求传给规划器和元素艺术指导，并绑定内容与布局哈希。
- `production_method`明确选择`native_assembly`、`source_photo`或`generated_editorial`。旧记录的`auto`保持兼容。原生产品构图不进入背景生成，仍执行来源像素与最终成图审查。
- 可辨的普通生活静物能够承担编辑叙事。产品主体与文字由原生层承担，生成层和原生层不重复绘制同一物件。
- 当前图上文案独立传入创作和审校。原帖标题作为背景，明确指定的图标题和参考句分开处理；通过既有修复流程纠正遗漏。
- 模型失败保留安全的阶段、业务错误码及HTTP状态，原始响应和凭证不进入作品或公开日志。

真实验证保留了成功与失败记录：朋友圈编辑静物图实际生成完成；两次较早尝试在文案调用或最终质量检查中未完成。极简产品主视觉另以已完成作品为父版本，实际复用已审文案，重新构图并渲染PNG；图像生成尝试为0、来源像素证明齐全。最终审校接口未返回完整协议，因此该版本保留为待审草稿，未标记ready。当前图仍受单正面主体和原长文案限制，不能据此宣称达到所参考产品阵列的视觉精度。

## 商城快照

2026年10月24日，从当前公开导航发现631条检索商品和337条直接导航商品，去重927条。899条取得可校验的公开详情，展开3255个SKU；28条详情明确返回`noData`，不进入可用目录。110个公开TAG均已尝试，其中108个分页计数核对完整，2个没有返回总数。没有可验证的全站总索引，覆盖范围保留为公开导航及其检索并集。

素材覆盖本轮详情中的SKU图库、选中SKU图库、商品详情图片与产品视频：38223条来源关联、25148个去重地址，全部已下载；去重为23776个内容对象，共13,309,441,636字节（约13.3GB），逐文件SHA复核无缺失、无不符。大文件归档位于实验室服务器，应用保留轻量目录与素材索引。本地可搜索查看器由实际快照生成。

其中一张1920×47246的详情长图超过即时渲染界限，完整原始字节以`header_and_source_bytes`归档并标记`render_eligible=false`；保留原失败与修复记录，不把归档成功冒充可直接渲染。

资料按品牌与销售商分别记录，第三方商品不冒充华为制造。参数只取明确选中SKU的参数区和属性；参数脚注原样保留。缺参数时仅使用该SKU的真实商品名称作为最小锚点，不推导额外性能。内部`Fact.sku_scope`记录适用版本，数字SKU不作为公开广告脚注。

旧同名知识优先；商城同名歧义不自动嫁接。当前884个名称唯一且未被旧资料优先覆盖的商城条目进入Agent目录。`read_catalog(query=...)`支持搜索超过前50条的新品，避免大目录被观察长度截断后不可发现。

素材按需在异步检索中下载，校验官方精确CDN、公网地址、TLS、类型、大小、像素与实际SHA。图片GET仅恢复已缓存文件。详情长图不会因下载成功就被标成透明产品主体或拍摄样张。

## 重现

```powershell
python scripts/discover_vmall_catalog.py --output runtime/vmall-catalog-20261024
python scripts/sync_vmall_materials.py --discovery runtime/vmall-catalog-20261024/discovery.json --output runtime/vmall-archive --download
python scripts/export_vmall_snapshot.py --discovery runtime/vmall-catalog-20261024/discovery.json --archive runtime/vmall-archive --output runtime/vmall-export
python scripts/build_vmall_explorer.py --source data/vmall_catalog.json
```

将导出的`catalog.json`、`assets.json`分别放到`data/vmall_catalog.json`、`data/vmall_assets.json`即可提供本地目录；完整原始字节归档与业务代码分开保存。这两份生成文件不提交到代码仓库，脚本和来源记录可以重建。

全量回归1796项通过、6项跳过；收尾模型错误诊断的73项相关检查通过。集合存在重叠，不相加作为总测试数。真实产品来源、下载统计和图文成图另外记录，不由单元测试或模型审美分替代。
