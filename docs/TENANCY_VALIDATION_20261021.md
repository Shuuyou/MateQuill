# MateQuill 企业与门店协作验收

日期：2026-10-21。本轮将单人创作产品扩展为总部、门店、销售员和独立合作企业共同使用的产品。

## 已落地的工作流程

总部创建推广活动，选择产品、门店及内容要求，发布带版本的门店任务。店员领取后，在原有拍照、语音和自然语言输入中继续创作，送出实际成稿；店长或审稿人查看正文与选中配图，批注或批准。店员登记发布平台与完成时间，总部汇总任务状态。活动更新、撤回和授权到期会反映到后续任务操作。

门店画像参与批量策划的人群、场景、叙事和画面分配。新品资料沿用原文预览、确认入库与事实溯源流程；电脑、手机、平板可围绕同一顾客任务生成华为生态内容。海报继续提供可编辑文字与布局、撤销重做和多格式导出。

独立代理采用独立企业账户，通过面向指定企业的活动授权协作。活动快照与各企业的成员、素材、私有成稿分别管理。企业内部通过带门店范围的任职组织店长、店员、区域经理和审核人员。

## 实际验证记录

- GitHub 核心版本 `9dfb3c77a139f0fac2a80ffe46c086d3ee495fe4` 的持续集成通过：后端 **478 项测试通过**，前端 production 构建通过。[检查记录](https://github.com/Shuuyou/MateQuill/actions/runs/39617200274)。该数字对应此版本，不代替后续提交的检查结果。
- 最终本地完整回归 **479 passed，0 skipped**；生成任务耐久性与 PostgreSQL 专用检查在独立测试数据库实际执行。新增历史接口用例验证 PostgreSQL JSONB 提取、大型正文与海报仅返回标题等元数据、跨企业空列表和匿名访问拒绝。前端正式构建、类型检查及 12 项 HTTPS 入口配置检查通过。
- 本地独立 PostgreSQL 18 使用迁移所有者和受限应用角色，验证强制行级隔离、连接池事务上下文清理、无身份读写拒绝，以及运行账号无法关闭隔离策略。
- 本地校园店账号实际提交电脑、手机、平板的创作任务，25.2 秒完成，成稿状态为 ready；官方配图与 HTML 导出均返回 200。另一企业读取该成稿、导出和任务均返回 404。该耗时是单次功能验收记录。
- 浏览器实际完成总部发布、校园店领取、模型生成、店长审核通过、店员登记发布的闭环，并完成独立合作企业接收定向活动。
- 企业共享成稿回归覆盖跨店阅读与限定配图、作者素材库隔离、取消共享后失效。成稿图片沿用原资源的企业、门店与内容摘要验证。
- 持久化任务回归覆盖重复提交、任务内容冲突、租约抢占、成员撤权、活动撤回、取消与恢复，以及“成稿已提交、worker 尚未完成时重启”的恢复窗口；最后一项在额度为 1 时仍复用同一份结果与一次用量。
- 创作历史优化后，在本地真实 PostgreSQL 服务再次登录校园店账号，历史接口返回 200，并包含已保存的生态成稿。

## 工程交付

认证和权限位于 `app/tenancy`；活动协作、持久化生成、产品知识、媒体与创作资源分别维护。Next.js 16 通过同源服务端代理携带会话及工作区前置条件。数据库迁移、生产配置示例、账号初始化工具和 CI 随代码交付。演示企业与门店明确标记为演示数据，账号密码在受 Git 忽略的本地运行文件内生成。

具体数据库、角色、会话、任务恢复和 HTTPS 运行方式见 [运行手册](TENANCY_OPERATIONS.md)。

本轮发布目标为本地、GitHub 与阿里云；按团队安排，魔搭创空间保留供次日上午展示的既有稳定版本。
