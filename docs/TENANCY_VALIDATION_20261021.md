# MateQuill 企业与门店协作验收

日期：2026-10-21。本轮将单人创作产品扩展为总部、门店、销售员和独立合作企业共同使用的产品。

## 已落地的工作流程

总部创建推广活动，选择产品、门店及内容要求，发布带版本的门店任务。店员领取后，在原有拍照、语音和自然语言输入中继续创作，送出实际成稿；店长或审稿人查看正文与选中配图，批注或批准。店员登记发布平台与完成时间，总部汇总任务状态。活动更新、撤回和授权到期会反映到后续任务操作。

门店画像参与批量策划的人群、场景、叙事和画面分配。新品资料沿用原文预览、确认入库与事实溯源流程；电脑、手机、平板可围绕同一顾客任务生成华为生态内容。海报继续提供可编辑文字与布局、撤销重做和多格式导出。

独立代理采用独立企业账户，通过面向指定企业的活动授权协作。活动快照与各企业的成员、素材、私有成稿分别管理。企业内部通过带门店范围的任职组织店长、店员、区域经理和审核人员。

## 工程交付

认证和权限位于 `app/tenancy`；活动协作、持久化生成、产品知识、媒体与创作资源分别维护。Next.js 16 通过同源服务端代理携带会话及工作区前置条件。数据库迁移、生产配置示例、账号初始化工具和 CI 随代码交付。演示企业与门店明确标记为演示数据，账号密码在受 Git 忽略的本地运行文件内生成。

具体数据库、角色、会话、任务恢复和 HTTPS 运行方式见 [运行手册](TENANCY_OPERATIONS.md)。

本轮发布目标为本地、GitHub 与阿里云；按团队安排，魔搭创空间保留供次日上午展示的既有稳定版本。
