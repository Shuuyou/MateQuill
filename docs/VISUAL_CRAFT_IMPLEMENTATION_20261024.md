## 从表达意图到制作参数

已实际研究的小米、华为及 OPPO 公开案例说明：产品造型、真实角度、文字命题和阅读层级应互相支撑，品牌主视觉与门店叙事都可以成立。这是本项目采用的制作方法，未据此声称营销效果或学术 SOTA 排名。

文案生成在原有有界调用中接收 `current_copy_commission` 与可选 `copy_craft_contract`。同次输出可包含短 `craft_decisions`：命题、产品/任务锚点、画面兑现、少量候选与取舍、最终选句、语义断行和条件位置。候选与工单不是额外获准发布的文案；最终卡片仍须独立逐句审阅。用户明确指定的图上原句保持独立委托，不能被原帖标题覆盖。

“轻一点”“有落地感”“让双环成为焦点”是艺术意图，不能直接当作执行结果。真实执行落在已有原生参数：区域位置与尺寸、`font_scale`、字重、字距、行距、色彩、层级、二维阴影及 `contact_shadow`。它们不等于物理重打光、改变材质或合成新视角。字形实际墨迹与文本框不同，应查看实际渲染和字体度量。

字号分为两种明确语义：`font_fit=adaptive` 沿用平台角色可读下限，`font_scale` 是可适配上限；`font_fit=authored` 要求文字区域提供 `font_scale` 目标值，保留 20 px 硬下限，不静默缩小或抬高到默认字号，空间不足时尝试安全扩展或报告溢出。这样，精确的 23 px 颜色标签与需要保持阅读尺度的正文各有明确约束。03 已按 authored 重渲染，像素哈希保持一致，过程记录在报告的 `schema_renderer_correction`。

## Agent 工具接口

先用 `read_artifact` 读取当前已授权设计。返回精简当前方案的页、区域 ID、相应文字和素材 ID；`key` 可优先精读已知页/区域。省略的区域有索引与 `has_more`，不通过截断 JSON 返回半个对象。

`revise_design` 的可选结构化字段：

```json
{
  "instruction": "把当前标题字距收紧一点，保留原句",
  "craft_edit": {
    "page_id": "实际返回的页ID",
    "region_id": "实际返回的标题区域ID",
    "values": {"letter_spacing": -1.25},
    "goal": "收紧该标题的字距"
  }
}
```

`CraftEditInput` 只接受 `page_id / region_id / values / goal`；可用参数由服务端 `REGION_CONTROLS` 和目标区域类型约束。模型不得回传另一份基线、源文稿 ID、改写文字或替换 `asset_id/text_id`。基线来自当前授权父作品；微调参与原有幂等效果键。普通自然语言调整继续使用已有路径。

`apply_craft_controls` 生成副本和冻结工单，通过整份计划比较确认只改变指定区域的获准参数。工单摘要与包含完整基线的校验对象分开保存，避免把大基线嵌入公开方案。最终仍需原生编译、来源检查和实际成图审阅；计划层面的范围校验不能替代对最终文档的核对。

服务的结构化微调分支直接恢复已授权父作品的真实资产与审定文字，跳过重新选材、图片观察、门店研究及文案生成。缺少父稿审定文案时返回明确冲突，不隐式重写；原有生成底图保留相同字节。`PosterDocument.region_bindings` 保存区域到真实图层的对应关系，下一次修改沿用它；其他图层从父稿实际文档恢复，避免重编旧方案时回滚已完成的精修。旧稿没有对应关系时只尝试用原方案重新编译定位，不能凭相似标题猜另一图层。

微调后的最终渲染和独立审阅照常运行，但 `max_rounds=0`，审阅建议不会越过工单自动改动其他区域；需要修改时由下一次明确工单继续。一般新图创作仍保留原有有界精修。`ContactShadow` 是图像专属的独立地面椭圆；存在该效果时，单张 PNG 的快捷直返路径必须退出，实际走合成。
